Make Definitions Precise

On this page

Start here

Is 0 even? Try the definition. An integer is even if it can be written as twice an integer. Since 0=2⋅00=2\cdot0, it qualifies. So does −6=2⋅(−3)-6=2\cdot(-3). A useful definition tells you how to decide borderline cases.

Worked example

Call two integers equivalent modulo 5 when their difference is a multiple of 5. For example, 2 and 7 are equivalent because 7−2=57-2=5.

Suppose a game tracks only this equivalence and tells you to add 3. Starting from 2 gives 5, and starting from 7 gives 10. Both results are still equivalent. In general, if a−ba-b is a multiple of 5, then (a+3)−(b+3)=a−b(a+3)-(b+3)=a-b is too. The rule is well-defined because the outcome, as measured by equivalence, does not depend on the representative you chose.

A quick definition check is to name the allowed objects, test a clear example and a boundary example, then ask whether a change of representation changes the answer.

Try it

  • Practice. A teammate defines a square as “a shape with four equal sides.” Give an example that passes the test but should be excluded. Repair the definition for ordinary quadrilaterals.
  • Stretch. Fractions can represent the same number in different ways. Someone proposes taking the numerator as a property of the number. Show why this fails and give a property that survives changing the fraction.

Check your work

Practice. A rhombus with angles of 60∘60^\circ and 120∘120^\circ passes. Require four equal sides and four right angles.

Stretch. 1/2=2/41/2=2/4, but the numerators are 1 and 2. Whether the fraction is greater than 0 is a property of the number, independent of the fraction used to represent it.
