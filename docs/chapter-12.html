Count the Same Objects Two Ways

On this page

  • Start here
  • Worked example
  • Try it
  • Check your work

Start here

A bijection matches each object on one side to exactly one on the other, and vice versa. For instance, match each subset of a five-item menu with the five yes/no choices that describe it. There are 25=322^5=32 subsets.

Worked example

In a club, count attendance across a week. You can count the names on each day's sign-in sheet and add the daily totals. Or you can count the days each person attended and add the personal totals. These methods agree because both count the same pairs (person,day)(\text{person},\text{day}).

That is double counting. Write down one item you are counting before you count by either method. This makes it easier to catch accidental repeats or gaps.

Try it

  • Practice. Six people each send one card to every other person. How many cards are there? Explain why the answer differs from the handshake count.
  • Stretch. In a finite group, every person has an integer number of friendships, and friendship is mutual. Prove the number of people with an odd friendship count is even.

Check your work

Practice. There are 6⋅5=306\cdot5=30 cards. A card from Ana to Bo is distinct from a card from Bo to Ana.

Stretch. Count friendship ends. The sum of the individual counts is twice the number of friendships, hence even. The even counts contribute an even total, so the number of odd counts must be even.
