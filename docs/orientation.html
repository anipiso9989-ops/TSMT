Learn to solve problems when nobody has told you which method to use. You'll start with small examples you can check by hand, then learn to prove claims, choose strategies, test models, and ask questions of your own.

What you need to start

You can begin with basic arithmetic, fractions, and simple equations. When a new term appears, read its example and try making one of your own. Part I explains what a proof asks you to do, one step at a time.

Start with Chapter 1 and follow the chapter order through Part I. If you already write proofs, try the checkpoint at the end of 01-Part-I-Foundations.md. If you can finish it and explain each step, start Part II.

How to study one chapter

  1. Read the opening question. Spend a minute trying it on paper.
  2. Work through the example. Cover the next step and predict it. Ask which rule makes the step valid.
  3. Try the practice problem. Write an answer before scrolling to the check. If it differs from yours, locate the first step where the arguments diverge.
  4. Try the stretch problem. If you get stuck, name the missing step and try a smaller case. Return the next day and solve it from a blank page.
  5. Test transfer. A week later, try a problem that uses the same idea in a new setting. Decide which approach to use before looking up the chapter.

One focused session can fit into 25 minutes. Spend about five minutes on the example, fifteen trying problems, and five checking your reasoning. Take longer if a proof needs it.

What each part trains

Part Chapters What you should be able to do
I · Foundations 1–6 Define terms, follow implications, and write a complete proof.
II · Problem solving 7–17 Find what stays fixed, exploit symmetry, count strategically, and work backwards.
III · Advanced thinking 18–24 Generalize proofs, combine methods, and justify bounds and optimal answers.
IV · Applied reasoning 25–30 Build a model, estimate a scale, check computations, and interpret data.
V · Independent research 31–35 Form a conjecture, find its boundaries, and make progress on your own question.

Each part ends with a checkpoint that mixes skills. Work it without a named method. If you get stuck, use the Principle Map to find a chapter to revisit.

What progress looks like

After a solution, write one sentence for each question.

  • Choice. What feature of the problem suggested the first useful move?
  • Proof. What justifies the step most likely to be challenged?
  • Boundary. Which assumption could you change to make the argument fail?

Keep a few old solutions. Rework one later using a different method or with a condition changed. When you can spot the method in a new problem and defend every important step, the skill is becoming yours.
