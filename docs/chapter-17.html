Work Backwards From the Goal

On this page

Start here

Suppose you want to prove x2−6x+9≥0x^2-6x+9\ge0. A square is always nonnegative. Can you find a square that matches the expression? Expanding (x−3)2(x-3)^2 gives the expression exactly.

Worked example

Prove a2+b2≥2aba^2+b^2\ge2ab. Read backwards. What would guarantee the result? If a2+b2−2aba^2+b^2-2ab were a square, it would be nonnegative. The missing object is (a−b)2(a-b)^2. Now write the proof forwards.

(a−b)2≥0⇒a2+b2−2ab≥0⇒a2+b2≥2ab.(a-b)^2\ge0\quad\Longrightarrow\quad a^2+b^2-2ab\ge0\quad\Longrightarrow\quad a^2+b^2\ge2ab.

An auxiliary object is something you introduce to make the argument possible, such as this square or a line in a diagram. When reasoning backwards, check that each condition you find is sufficient to get back to the goal.

Try it

  • Practice. Prove x2+4x+5≥1x^2+4x+5\ge1 for every real xx.
  • Stretch. Prove ab≤25ab\le25 when a+b=10a+b=10, and determine exactly when equality holds. Find an auxiliary square involving the difference.

Check your work

Practice. x2+4x+5=(x+2)2+1≥1x^2+4x+5=(x+2)^2+1\ge1.

Stretch. (a+b)2−4ab=(a−b)2≥0(a+b)^2-4ab=(a-b)^2\ge0, so 4ab≤1004ab\le100. Equality requires a=ba=b, and the sum then forces a=b=5a=b=5.
